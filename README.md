# Restaurant Reservation — Experiment 1 + Experiment 2

## Included
- React + Vite application
- Separate reusable components
- Restaurant search and cuisine filter
- Restaurant details and table selection
- Reservation form with validation
- Booking confirmation
- My Bookings page
- Bookings saved in browser localStorage
- Vitest + React Testing Library tests

## Run
```bash
npm install
npm run dev
```

## Run tests
```bash
npm run test:run
```

## Build
```bash
npm run build
```

Note: localStorage saves bookings in this browser only. This project does not use a backend database.
